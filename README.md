# Artificial Intelligence Lab Solutions (CSE401) - Amity University

This repository contains fully formatted, properly indented, and standalone Python implementations for Artificial Intelligence Lab experiments (Q1 to Q5).

---

## 📂 Repository Contents

| File | Experiment Name | Algorithm / Technique |
| :--- | :--- | :--- |
| [`q1_water_jug_bfs.py`](./q1_water_jug_bfs.py) | **Experiment 1**: Water Jug Problem | Breadth-First Search (BFS) |
| [`q2_greedy_and_astar_search.py`](./q2_greedy_and_astar_search.py) | **Experiment 2**: Heuristic Search | Greedy Best-First Search & A* Search |
| [`q3_graph_colouring_backtracking.py`](./q3_graph_colouring_backtracking.py) | **Experiment 3**: Constraint Satisfaction | Backtracking Algorithm |
| [`q4_tic_tac_toe_minimax.py`](./q4_tic_tac_toe_minimax.py) | **Experiment 4**: Game Playing | Minimax Algorithm |
| [`q5_knapsack_dp.py`](./q5_knapsack_dp.py) | **Experiment 5**: Optimization Problem | 0/1 Knapsack using Dynamic Programming |
| [`cse401_ai_lab_solutions_q1_to_q5.py`](./cse401_ai_lab_solutions_q1_to_q5.py) | **Consolidated Script** | Experiments 1 to 5 in a single runner file |

## 🚀 How to Run

Each file is self-contained with no external dependencies required (uses standard library modules like `collections` and `heapq`).

### 1. Water Jug Problem (BFS)
```bash
python q1_water_jug_bfs.py
```

### 2. Greedy Best-First and A* Search
```bash
python q2_greedy_and_astar_search.py
```

### 3. Graph Colouring (Backtracking)
```bash
python q3_graph_colouring_backtracking.py
```

### 4. Tic-Tac-Toe (Minimax)
```bash
python q4_tic_tac_toe_minimax.py
```

### 5. 0/1 Knapsack Problem (DP)
```bash
python q5_knapsack_dp.py
```
